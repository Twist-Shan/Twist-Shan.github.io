STIX fonts

The source PDFs for the scientific figures use STIXGeneral Regular and Italic for some mathematical lettering. The exported SVG figures preserve this lettering as vector outlines. The STIX notice and SIL Open Font License 1.1 are reproduced from the Matplotlib distribution.

Design guidance

The implementation consulted the design-taste-frontend guidance from Antigravity Awesome Skills, distributed under the MIT license. This is a design reference, not a browser dependency. The visual template follows the author’s existing Pareto Frontier blog.

Read the design guidance license · Source revision

Page implementation and typography

The interactive diagrams and 3D view use native JavaScript, SVG, and Canvas. This page does not bundle Plotly.js, KaTeX, or their fonts. Body typography uses fonts installed on the reader’s device. Times New Roman lettering in the scientific figures is exported from the supplied paper PDFs as vector outlines; no Times New Roman font file is bundled.
